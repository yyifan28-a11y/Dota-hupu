## 时效规则

- `snapshot`：会被新增 S3 数据改变。线索正文必须带“截至 M 月 D 日”，截止日为出题日前一天。
- `s2_closed`：只依赖已结束的 S2，通常不需要日期。
- `historical`：描述某场已经发生的比赛，或“曾经发生过”的事件，通常不需要日期。
- `mixed_baseline`：单场事实与动态生涯基准比较。必须标出基准统计日期。

## 建议工作流

1. 在对话中从 `clueCatalog` 选择线索类型并核验真实数据。
2. 新题先保存为 `draft` 或 `backup`。
3. 为五条线索分别填写并复核 `verification`，不得只重复提示原文。
4. 固定五条线索、顺序与出题日期后，改为 `active`。
5. 经确认后再同步进网站轮换；未经确认不上传腾讯云。
