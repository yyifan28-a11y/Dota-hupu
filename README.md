# Dota2 内战工具

这是一个给 Dota2 内战群使用的网页工具。当前版本是“网页 + Node 后端 + SQLite 数据库”。

## 当前功能

- 选手数据库：记录昵称、Steam / Dota ID、0-10 评分、备注。
- 评分管理：评分可手动更新，并记录最后修改时间。
- 管理员密码：新增、删除、更新评分、生成对阵、保存比赛、导入、清空数据都需要管理员密码。
- 管理员入口：普通成员只能查看公开数据；评分、最后改分时间、添加/删除人员等管理操作只在管理员模式显示。
- 排名页：可按评分、胜率、净胜场、场次排序查看所有选手。
- 对阵生成器：选择 10 名选手，自动生成 5v5 天辉 / 夜魇。
- 选择计数器：对阵生成器会显示当前已选人数，例如 `已选 6/10`。
- 分队预设：可强制两名选手同队，或强制两名选手成为对手。
- 平衡逻辑：优先保证双方总评分差小于等于 1。
- 生成偏好：可选“常用位置优先”或“人员组合优先”。
- 比赛记录：保存胜负、比分 / 时长、备注，并记录每位选手本场 1-5 号位。
- 比赛明细：管理员录入比赛时，可逐个选手记录英雄选择、GPM、XPM、10分钟经济、伤害量、治疗量和特殊内容。
- 位置倾向：根据历史比赛里的本场位置自动统计，不再使用固定预设位置。
- 数据备份：支持导出 / 导入 JSON。

## 怎么运行

在这个文件夹打开命令行，执行：

```bash
npm start
```

然后打开：

```text
http://localhost:3000
```

第一次运行时会自动创建或升级 `dota.db` 数据库文件。

## 管理员入口

默认管理员密码是：

```text
admin123
```

正式给群友使用前，建议你改密码。PowerShell 里可以这样启动：

```powershell
$env:ADMIN_PASSWORD="你的新密码"; npm start
```

这个密码只适合小群内部工具使用。如果要公开部署到公网，后续建议加登录系统。

网页里需要先进入“数据”页的“管理员入口”，输入管理员密码后，才会显示新增选手、删除选手、更新评分、保存比赛、导入和清空数据等管理操作。

## 对阵生成逻辑

生成对阵时，系统会枚举所有可能的 5v5 组合：

1. 先过滤掉不满足“强制同队 / 强制对手”预设的组合。
2. 再过滤掉双方总评分差大于 1 的组合。
3. 如果选择“常用位置优先”，会尽量减少同队选手的位置倾向重复。
4. 如果选择“人员组合优先”，会尽量减少历史上已经同队过的组合。

## 数据保存在哪里

数据保存在项目目录下的 SQLite 数据库文件：

```text
dota.db
```

建议定期备份这个文件，或者在网页“数据”页面导出 JSON。

## 怎么给群友访问

如果只是同一个局域网内测试：

1. 你的电脑保持 `npm start` 不要关。
2. 查询你电脑的局域网 IP。
3. 群友访问 `http://你的IP:3000`。

如果想让不在同一个网络的群友访问，需要部署到云服务器。
